# core/agent.md

## 1. 技术设计要点/总结
*   **职责**: `Agent` 类是业务逻辑的编排者，负责将 `ChatSession` 的原始输出流包装成结构化的事件流。
*   **异步流处理**: 使用 `async for` 迭代 LLM 响应，并结合 `parser` 模块进行实时解析。
*   **解耦设计**: `Agent` 只产生事件（Event），不负责具体的 UI 渲染或文件写入，实现了与展示层的解耦。
*   **调试支持**: 内置 `debug_mode`，可在输出中实时查看原始事件包结构。
