# core/agent.py 伴生文档

## (1) 技术设计要点/总结
- **事件中心**: Agent 作为 LLM 输出解析与业务处理的中转站，负责将原始流转化为结构化事件。
- **透明分发**: 通过 `_handle_event` 机制实现了基础 UI 事件（TextChunk/StatsUpdate）与业务动作事件的解耦。
- **状态维护**: 在运行过程中自动累加 Assistant 的完整回复（包括 XML 标签触发词），确保对话历史的一致性。

## (2) 变更记录流水
- **2026.02.06**:
  - **[解耦]**: 深度分离业务逻辑，移除所有具体业务事件引用。
  - **[标准]**: 按照 Google 规范补全 `Agent` 类及其所有方法的 Docstring。
  - **[风格]**: 实现了长行折行、嵌套调用换行规范。
  - **[功能]**: 整合并规范化了 `_handle_default` 兜底处理逻辑。
