# core/consumer.md

## 1. 技术设计要点/总结
*   **职责**: “动手动脚者”，负责实质性地执行 `Agent` 生成的动作（如文件保存）和 UI 渲染（打字机效果）。
*   **事件循环**: 维持一个异步的 `while` 循环，协调用户输入与 Agent 的响应。
*   **解耦逻辑**: 它依赖于接口而非具体实现，可以方便地扩展新的事件处理逻辑（如 `_handle_filewritestart`）。
