# core/parser.md

## 1. 技术设计要点/总结
*   **职责**: 提供 `parse_stream` 异步生成器，利用正则表达式拦截 XML 风格的工具调用标签。
*   **健壮性**: 
    *   贪心状态机：通过 `TEXT` 和 `CALLING` 状态管理，实现标签即时截流与自动回退。
    *   容错处理：支持非闭合标签抢救及误报起始符（如数学符号）的智能判定。
*   **流式输出**: 在普通文本状态下实现字符级渲染，在调用状态下保持截流直至判定完成。
