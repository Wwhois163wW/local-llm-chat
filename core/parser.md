# core/parser.md

## 1. 技术设计要点/总结
*   **职责**: 提供 `parse_stream` 异步生成器，利用正则表达式拦截 XML 风格的工具调用标签。
*   **健壮性**: 
    *   状态机管理：管理文件写入的开启与关闭状态。
    *   正则优化：支持 `<write_file path="...">` 和 `<read_file path="..." />` 的解析。
*   **流式输出**: 在解析标签的同时，将非标签内容实时作为 `TextChunk` 弹出。
